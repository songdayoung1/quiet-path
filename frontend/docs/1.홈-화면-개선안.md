# Quiet Path Home 재정리 계획안

## Summary

현재 Home는 이미 `Current Path`, `오늘 기록`, `Streak Heatmap`, `월간 요약`, `사진 미리보기`까지 들어와 있어 기능은 부족하지 않다. 문제는 기능 부족이 아니라 `위계 부족`이다. 지금은 많은 정보가 비슷한 카드 톤으로 평평하게 쌓여 있어, 유저가 첫 3초 안에 `지금 여기서 뭘 해야 하는지`와 `기록하면 무엇이 남는지`를 강하게 느끼기 어렵다.

이번 개편의 핵심은 Home를 `대기 화면`에서 `행동 + 보상 + 누적 가치가 보이는 대시보드`로 바꾸는 것이다. 이미 적용된 `Streak Heatmap`과 `물방울 저장 인터랙션`은 유지하고, 그 위에 `Today's Card`를 Home의 1순위 보상 요소로 올린다.

---

## 현재 구조 진단

### 이미 반영된 것
- `Streak Heatmap`은 Home에 들어가 있음
- 기록 저장 시 물방울 인터랙션이 이미 존재함
- Home에 `Current Path`, `오늘 기록 유도`, `Recent Scene`, `월간 요약`, `사진 미리보기`가 이미 있음
- Journal은 `앨범 / 기록 / 캘린더` 구조로 이전보다 정리되어 있음

### 아직 남아 있는 핵심 문제
- Home의 카드들이 대부분 `white/70 + blur + rounded` 계열이라 시각적 위계가 약함
- `오늘 기록 전/후` 상태 차이가 여전히 작음
- 기록 완료 후 보상감이 `상태 안내문` 수준에 머물고 있음
- `Recent Scene`, `월간 요약`, `사진 미리보기`가 각각 비슷한 강도로 쌓여 있어 핵심이 흐림
- Home가 `앱의 가치 설명`보다 `카드 목록`처럼 느껴짐
- 하단 탭 이름 `Now / Journal / Flow / Path`는 첫 진입 유저에게 직관적이지 않음

---

## Home의 역할 재정의

Home는 아래 3가지를 한 번에 해야 한다.

1. `Action`
   오늘 기록을 남기게 만든다.
2. `Progress`
   지금 Path 위에서 얼마나 움직였는지 보이게 한다.
3. `Memory`
   기록이 쌓였고 다시 꺼내볼 가치가 있다는 걸 보여준다.

즉 Home는 설명 화면이 아니라 `오늘의 행동을 유도하고, 기록 후 보상을 보여주며, 지난 축적을 미리 맛보게 하는 화면`이어야 한다.

## 최종 정보 구조

### 1. Hero Header
- 날짜
- 짧은 헤드라인
- 최근 무드 또는 오늘 상태

문구 톤
- `오늘 남기고 싶은 장면이 있나요?`
- `하루를 돌아보며 방향을 만들어가요.`
- `오늘은 어디로 움직였나요?`

규칙
- 지금처럼 짧고 담백한 문구 유지
- 철학 문장 금지
- 설명보다 행동 유도 우선

### 2. Home Hero = Today's Card
Home의 최상단 핵심 카드로 고정한다.

#### 기록 전 상태
- 질문: `오늘 남기고 싶은 장면이 있나요?`
- 보조 문구: `한 줄만 남겨도 충분해요.`
- 큰 CTA: `기록 남기기`
- 시각 요소:
  - 물결/물방울 계열의 작은 일러스트 또는 추상 형태
  - 지금 색감 안에서 가장 강조되는 카드여야 함

#### 기록 후 상태
- 체크마크/안내문 대신 `Today's Card` 자체가 결과물로 변해야 함
- 카드 내용:
  - `oneWordText`
  - `moodCode`
  - `sceneText` 일부
  - 사진이 있으면 썸네일 또는 카드 배경 일부 사용
- 하단 액션:
  - `다시 보기`
  - `수정하기`
  - 선택적으로 `공유용으로 보기`
- 시각 방향:
  - 스크린샷하고 싶을 정도로 예쁜 카드
  - 인스타 스토리 카드처럼 보이되 Quiet Path 톤 유지
  - 너무 SNS스럽지 않게

핵심 효과
- `기록 전`에는 행동 유도
- `기록 후`에는 즉시 보상

### 3. Current Path Strip
현재의 큰 카드보다 압축해서 Home 2순위 정보로 둔다.

표시 정보
- Path 이름
- Key Question
- Consistency
- 기록 일수
- Review 예정일

규칙
- 지금처럼 큰 정보 카드보다 `요약 스트립`에 가깝게 만든다
- Home의 주인공은 Path가 아니라 `오늘의 기록`이어야 한다

### 4. Quick Actions
2~3개만 유지
- `이번 달 보기`
- `지난 흐름 보기`
- 선택: `둘러보기`

규칙
- 모두 같은 강도로 크지 않게
- Home의 보조 이동 도구로만 둔다

### 5. Progress Band
Home에서 누적 가치를 보여주는 영역

구성
- `Streak Heatmap`
- 이번 달 기록 수
- Consistency
- Top Mood

규칙
- Heatmap은 유지하되, 카드 하나를 통째로 차지하는 방식보다 `누적 가치 영역` 안에 묶는다
- “내가 이만큼 걸어왔다”는 감각을 줘야 함

### 6. Memory Preview
기록이 남는다는 감각을 주는 영역

구성
- `이번 달 장면 미리보기` 3~4개
- 필요하면 `최근 장면 1개`는 여기로 흡수
- 별도 `Recent Scene` 단독 카드로 분리하지 않고, Memory 섹션으로 묶는 방향을 권장

핵심
- 사진이 있든 없든 `기억`을 미리 보여주는 섹션이어야 함
- Journal의 가치를 Home에서 미리 예고하는 역할

## 시각 위계 시스템

현재 문제는 카드가 모두 비슷하게 보여서 중요도가 안 보이는 것이다. 아래 4단 위계로 강제한다.

### Tier 1. Hero
- `Today's Card`
- 가장 큰 카드
- 배경 톤/질감/그림자 차별화
- Home에서 가장 먼저 시선이 가야 함

### Tier 2. Path / Progress
- `Current Path Strip`
- `Progress Band`
- 숫자/상태 중심
- Hero보다 작고 더 기능적으로 보이게

### Tier 3. Memory
- `이번 달 장면 미리보기`
- 사진/장면 중심
- Home 하단부에서 다음 탐색을 유도

### Tier 4. Utility
- 빠른 이동 버튼
- 작은 보조 CTA
- 보조 정보

## 삭제 또는 축소할 것

- `Recent Scene` 단독 카드
  - `Today's Card` 또는 `Memory Preview`에 흡수
- 큰 동기부여 텍스트 블록
- 모든 카드의 동일한 유리질감 스타일
- 보라색 포인트 하나에만 의존하는 강조 방식

---

## 유지할 것

- 전체적인 차분한 색감
- 물방울/물결 계열 인터랙션
- `Streak Heatmap`
- 무드 스티커
- 부드러운 카드/라운드/블러 감성 자체
  - 단, 모두 똑같이 쓰지 않음

## 하단 탭 정리 방향

현재 이름은 첫 진입 유저에게 목적이 불명확하다. v1.5 기준으로 화면 라벨은 더 직관적으로 바꾼다.

추천 라벨
- `Now` → `오늘`
- `Journal` → `기록`
- `Flow` → `둘러보기`
- `Path` → `여정`

원칙
- 내부 view key는 유지해도 됨
- 사용자에게 보이는 라벨만 바꿔도 효과 큼
- Home 구조 개편과 함께 탭 이해 부담도 같이 줄인다

## Gemini에 줄 화면 설계 지시사항

### 설계 목표
- Home를 `카드 리스트`가 아니라 `행동 + 보상 + 축적`이 있는 대시보드로 재구성
- `Today's Card`를 Home의 핵심 Hero로 설계
- 현재 Path는 Home의 주인공이 아니라 2순위 정보로 압축
- `Streak Heatmap`과 `월간 기록 가치`를 같은 Progress 영역으로 묶기
- `Recent Scene`은 분산하지 말고 Memory 섹션으로 통합
- 기존 색감은 유지하되 카드 위계와 질감 차이를 더 강하게 만들기

### 꼭 반영할 상태
- 기록 전 Home
- 기록 후 Home
- 사진 있는 Today’s Card
- 사진 없는 Today’s Card
- 기록이 거의 없는 신규 유저 Home
- 기록이 많이 쌓인 유저 Home

### 금지사항
- Home에 동일 톤 카드만 반복 배치
- 큰 철학 문구 배너
- Today’s Card를 단순 체크 상태로 처리
- Journal/Path 기능을 Home에 과하게 복사해 넣기
- 사진앱 같은 레이아웃

## 컴포넌트/인터페이스 변경 방향

### HomeView
필요한 변화
- `hasLoggedToday` 기반 분기만이 아니라 `todayRecord` 자체를 직접 렌더하는 구조로 변경
- `Recent Scene` 단독 섹션을 제거하거나 `Memory Preview`로 통합
- `Current Path` 카드 크기를 줄이고 요약형으로 재구성
- `Progress`와 `Memory` 섹션을 분리

### App Bottom Nav
변경 대상
- 하단 탭 라벨 텍스트
- 필요 시 아이콘 의미도 `오늘 / 기록 / 둘러보기 / 여정`에 맞게 미세 조정

### UI 컴포넌트
추가 또는 재활용 추천
- `TodaysCard`
- `ProgressBand`
- `MemoryPreviewStrip`
- 기존 `StreakHeatmap`, `MoodSticker`, `SoftButton`은 유지 활용

## 테스트 시나리오

### Home 상태 시나리오
- 기록이 없는 날: Hero가 기록 유도 카드로 보인다
- 기록이 있는 날: Hero가 Today’s Card 결과물로 바뀐다
- 사진이 있는 기록: Today’s Card와 Memory Preview에 반영된다
- 사진이 없는 기록: 카드가 텍스트/무드 중심으로 균형 있게 보인다
- Current Path가 없는 상태: Home가 비어 보이지 않고 Path 시작 유도 상태를 제공한다

### 이해도 시나리오
- 첫 진입 유저가 3초 안에 `기록 남기기` 액션을 찾을 수 있다
- 하단 탭 라벨만 보고도 각 탭의 목적을 추론할 수 있다
- Home에서 `이번 달 보기`와 `지난 흐름 보기`의 차이를 이해할 수 있다

### 시각 시나리오
- Hero / Progress / Memory / Utility 위계가 명확하다
- 카드가 전부 같은 톤으로 보이지 않는다
- Streak Heatmap이 묻히지 않지만 Home를 지배하지도 않는다

---

## Assumptions / Defaults

- 기존 색감은 유지하고, 위계 차이만 강화한다
- `Streak Heatmap`과 물방울 인터랙션은 그대로 살린다
- `Today's Card`는 새로운 독립 탭이 아니라 Home Hero 안에서 해결한다
- `Recent Scene`은 별도 단독 카드보다 Memory 섹션 통합이 기본값이다
- 하단 탭 라벨은 한국어 직관형으로 바꾸는 것을 기본안으로 둔다
- Home 개편은 백엔드 변경 없이 현재 프론트 상태 데이터로 설계 가능하다고 본다
