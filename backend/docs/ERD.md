# ERD (Quiet Path)

> 목적: 백엔드 구현을 위한 데이터 모델 스펙.  
> DB: MySQL 8 / InnoDB  
> 정책(확정):
> - User당 ACTIVE Path는 1개 (users.current_path_id로 강제)
> - Record는 하루 1개 (records unique(user_id, record_date))
> - Record는 작성 후 공유 버튼으로 PUBLIC 전환 (visibility/shared_at)
> - 공감은 공유된 Record에만 가능
> - 칭호는 획득형 (titles + user_titles + users.current_title_id)

## 1. tables

### users
- purpose: 회원 / 현재 ACTIVE path 및 장착 칭호 / 레벨/걸음수/설정값
- pk:
  - id (bigint)
- columns:
  - provider (varchar20) not null            # GOOGLE
  - provider_user_id (varchar128) not null   # google sub
  - email (varchar255) null
  - nickname (varchar30) not null
  - current_title_id (bigint) null
  - current_path_id (bigint) null
  - level (int) not null default 1
  - steps_taken (int) not null default 0
  - data_sync_enabled (tinyint) not null default 1
  - created_at (datetime) not null
  - updated_at (datetime) not null
  - last_login_at (datetime) null
- unique:
  - (provider, provider_user_id)
  - (nickname)
- index: (none)
- fk:
  - current_title_id -> titles.id
  - current_path_id -> paths.id
- rules:
  - a user has exactly 0 or 1 active path via current_path_id

---

### titles
- purpose: 칭호 마스터(전시/설명/활성)
- pk:
  - id (bigint)
- columns:
  - code (varchar50) not null
  - display_name (varchar50) not null
  - description (varchar255) null
  - is_active (tinyint) not null default 1
  - created_at (datetime) not null
- unique:
  - (code)
- index: (none)
- fk: (none)

---

### user_titles
- purpose: 유저가 획득한 칭호 이력
- pk:
  - id (bigint)
- columns:
  - user_id (bigint) not null
  - title_id (bigint) not null
  - acquired_at (datetime) not null
- unique:
  - (user_id, title_id)
- index:
  - (user_id, acquired_at)
- fk:
  - user_id -> users.id
  - title_id -> titles.id
- rules:
  - a user can acquire same title only once

---

### paths
- purpose: 유저의 방향(1 user = 0..n paths, but active only 1)
- pk:
  - id (bigint)
- columns:
  - user_id (bigint) not null
  - category_code (varchar20) not null
  - key_question (varchar255) not null
  - name (varchar100) not null
  - description (varchar500) null
  - start_at (datetime) not null
  - anchor_at (datetime) not null
  - status (varchar20) not null              # ACTIVE/CLOSED
  - closed_at (datetime) null
  - created_at (datetime) not null
  - updated_at (datetime) not null
- unique: (none)
- index:
  - (user_id, status, anchor_at)
  - (category_code, status, anchor_at)
- fk:
  - user_id -> users.id
- rules:
  - anchor_at is required
  - only one ACTIVE path is referenced by users.current_path_id

---

### records
- purpose: 하루 1개 journal 기록(작성 후 공유 가능)
- pk:
  - id (bigint)
- columns:
  - user_id (bigint) not null
  - path_id (bigint) not null
  - category_code (varchar20) not null       # denormalized from path
  - record_date (date) not null              # local date (KST 기준)
  - scene_text (varchar500) null
  - one_word_text (varchar200) null
  - tomorrow_text (varchar200) null
  - mood_code (varchar30) null
  - visibility (varchar10) not null default PRIVATE
  - shared_at (datetime) null
  - reaction_count (int) not null default 0
  - created_at (datetime) not null
  - updated_at (datetime) not null
- unique:
  - (user_id, record_date)
- index:
  - (path_id, record_date)
  - (visibility, category_code, shared_at, id)
- fk:
  - user_id -> users.id
  - path_id -> paths.id
- rules:
  - 하루 1개 정책: (user_id, record_date) unique
  - share action: set visibility=PUBLIC, shared_at=now

---

### reactions
- purpose: 공개 record에 대한 공감(하트)
- pk:
  - id (bigint)
- columns:
  - record_id (bigint) not null
  - user_id (bigint) not null
  - created_at (datetime) not null
- unique:
  - (user_id, record_id)
- index:
  - (record_id, created_at)
- fk:
  - record_id -> records.id
  - user_id -> users.id
- rules:
  - only PUBLIC records can be reacted (validated at service layer)

---

### path_summaries
- purpose: 종료된 path에 대한 AI 요약(markdown)
- pk:
  - id (bigint)
- columns:
  - path_id (bigint) not null
  - status (varchar20) not null
  - format (varchar20) not null default MARKDOWN
  - content (mediumtext) null
  - prompt_version (varchar30) null
  - model (varchar50) null
  - input_hash (char64) null
  - created_at (datetime) not null
  - updated_at (datetime) not null
- unique:
  - (path_id, prompt_version)
- index:
  - (path_id, status, updated_at)
- fk:
  - path_id -> paths.id
- rules:
  - summary can be regenerated by prompt_version change (optional)
